# «Неделя» — плагин Panopticon

Цели недели и недельный цикл: план в понедельник, цели на «Сегодня», вкладка «Неделя» (⌃⌘7). Всё хранится в обычном Org-файле `weeks.org`:

```org
* 2026-W42 · 12–18 октября
** Цели
*** TODO Закрыть найм SRE
*** Окно переключения ДЦ согласовано
** Итоги
```

Нужен Panopticon с API 1.8 и выше. Кнопки недель встают в календарь (его место `calendar.weekCell`), в листе плана — активные цели «Мои» из «Целей квартала», если они включены. Права: `index.read`, `files.edit`.

## Установка

Из каталога: «Настройки → Плагины → Каталог плагинов…» → «Неделя» → «Установить».

## Сборка

```bash
npm install
npm run build        # dist/main.js и dist/manifest.json
npm test
```

Или руками: положите `dist` в папку плагинов приложения под именем `week` («Настройки → Плагины → Открыть папку плагинов»), затем «Перезагрузить плагины».

`panopticon-api.ts` — копия `src/api/index.ts` приложения: типы API и `definePlugin`. Обновляйте её вместе с приложением.

## Релиз

Поднимите `version` в `manifest.json` и `package.json`, затем поставьте тег с этой версией — `git tag 0.4.0 && git push --tags`. Workflow `release.yml` соберёт плагин и выложит релиз с `manifest.json` и `main.js`; каталог возьмёт его оттуда.
